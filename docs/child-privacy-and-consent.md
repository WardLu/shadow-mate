# 儿童隐私与家长同意审核记录

状态：工程闸门已实现，法律闸门未清除。本文件是内部产品与技术准备记录，不是法律意见，也不代表已经满足任何特定司法辖区的正式要求。

## 当前产品边界

- 家长/监护人使用 Supabase Auth 账号登录；学习者不是独立账号。
- 云端学习者档案只保存显示名称、年级和学习状态。产品不要求学习者提供邮箱、手机号、生日、学校、地址、精确位置或照片。
- 页面访问统计与学习数据分开，当前使用 Vercel Web Analytics；正式运营前仍需完成第三方处理者、跨境、URL/Referrer 和儿童场景评估。
- 当前版本的朗读兜底仍使用浏览器本地 Piper；目标商业路线将使用自托管 MeloTTS API，动态朗读文本会进入影伴 TTS 服务，必须纳入第三方处理者、日志、缓存、删除和跨境评估。
- 本地学习状态仍可能保存在浏览器 `localStorage`；清除本机数据不会自动删除云端家庭数据。

## 当前内测边界（2026-08-12）

当前仅允许已知测试者参加非商业、小规模邀请制内测。内测不收费、不接入 Pro/订阅，也不因内测身份自动豁免儿童个人信息、家长同意、删除权或跨境处理要求。首轮测试应优先使用成人测试账号、昵称和模拟学习数据；当前登录家长自我声明加服务端记录仍不是所有目标市场都认可的可验证家长同意。

## 已实现的技术控制

创建第一个学习者或向家庭添加学习者前：

1. UI 要求登录用户勾选“我是孩子的家长或监护人”。
2. UI 明确链接到隐私说明，并提供“稍后设置”拒绝/退出路径。
3. 客户端向 `public.learning_guardian_consents` 写入：`household_id`、认证用户 `user_id`、`consent_type=learner_data_processing`、`policy_version=privacy-v1`。
4. `consented_at` 和 `created_at` 由数据库生成，客户端不能写入或修改时间戳。
5. `learning_profiles` 的 INSERT RLS 同时要求当前用户是 owner/guardian 且存在同版本同意记录；不能只绕过 UI 调 API 创建学习者。
6. 家庭删除通过外键级联删除同意记录；同意记录对客户端没有 UPDATE/DELETE 权限。

这是一项“登录家长自我声明 + 服务端审计记录”控制，不应在美国 COPPA、欧盟 GDPR 或其他要求可验证家长同意的地区直接宣传为已完成的可验证同意。

## 数据生命周期和家长权利

| 环节 | 当前实现 | 公开运营前必须确认 |
| --- | --- | --- |
| 收集 | 创建学习者前记录 `privacy-v1` 同意 | 告知文本、处理目的、必要性、拒绝后果和适用法律依据 |
| 使用 | 家庭成员 RLS 访问；学习状态用于家庭学习功能 | 是否存在画像、推荐、AI 处理或跨产品复用；默认关闭非必要用途 |
| 第三方 | Supabase 承载云端数据，Vercel 承载页面访问统计 | DPA、分处理者清单、数据所在地、跨境机制和儿童数据条款 |
| 导出 | 家庭 owner 可导出家庭 JSON | 申请身份核验、响应时限、导出格式和日志 |
| 更正 | owner/guardian 可编辑学习者档案 | 监护人/儿童权利请求的受理和核验流程 |
| 删除 | 删除学习者或整个家庭；数据表级联 | 删除请求 SLA、备份副本清除、日志保留和账号身份处理 |
| 撤回同意 | 当前没有自助“撤回但保留家庭/删除学习者”的独立流程 | 设计撤回入口、停止处理行为、历史记录处理和再次同意策略 |

## 适用地区初筛

产品没有锁定单一运营地区，以下只是触发器清单，不能替代地域策略和律师意见：

- **中国大陆**：若在中国境内通过网络收集、存储、使用儿童个人信息，应审阅 [《儿童个人信息网络保护规定》](https://www.cac.gov.cn/2019-08/23/c_1124913903.htm)（其中“儿童”为不满十四周岁的未成年人，并规定显著告知监护人、取得同意、最小必要、保留期限和删除等要求），同时审阅 [《中华人民共和国个人信息保护法》](https://www.npc.gov.cn/npc/c2/c30834/202108/t20210820_313088.html) 及未成年人网络保护、跨境和委托处理要求。
- **美国**：若服务面向不满 13 岁儿童，或运营方实际知道正在收集不满 13 岁儿童的信息，应审阅 FTC 的 [COPPA Rule 资源](https://www.ftc.gov/business-guidance/resources/childrens-online-privacy-protection-rule-coppa)和 [COPPA 法条说明](https://www.ftc.gov/legal-library/browse/statutes/childrens-online-privacy-protection-act)。当前勾选框不是已核验的 verifiable parental consent。
- **欧盟/欧洲经济区**：若服务直接面向儿童且以同意为处理基础，应审阅 [GDPR Article 8](https://eur-lex.europa.eu/eli/reg/2016/679/art_8/oj)；成员国可把年龄降到不低于 13 岁，并要求对家长责任人同意作合理核验。还应参考 [EDPB 儿童数据说明](https://www.edpb.europa.eu/topics/key-gdpr-concepts/children_en)的清晰、易懂、适龄和隐私保护原则。
- **英国**：若服务可能被儿童访问，应审阅 ICO 的 [Children’s Code](https://ico.org.uk/for-organisations/uk-gdpr-guidance-and-resources/childrens-code/)及最佳利益、年龄适配设计和默认高隐私要求。

## 法律审核闸门

以下项目完成并形成书面意见前，不得把儿童学习云端作为已清权的商业服务销售：

- [ ] 确定目标市场、服务是否面向儿童、年龄范围和年龄判断/地域限制策略。
- [ ] 律师审核隐私政策、家长同意文案、授权方式和“家长/监护人”身份核验强度；确认当前自我声明是否足够，或需邮件确认、二次确认、支付卡/人工等方法。
- [ ] 明确处理者/受托方、数据所在地、跨境传输、DPA 和子处理者清单。
- [ ] 定义保留期限、删除/更正/导出/撤回同意的可操作 SLA，包括备份和日志。
- [ ] 评估 Vercel Analytics、Supabase Auth、Supabase Database 和未来 AI/TTS 服务是否接触儿童个人信息。
- [ ] 完成儿童数据泄露、误删、越权访问和家长投诉的事故响应演练。
- [ ] 由法律顾问确认目标市场的消费者条款、退款/订阅、监护人授权和争议处理文本。
