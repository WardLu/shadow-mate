# 影伴使用指南

这份指南面向第一次使用影伴的家长。应用内左侧“指南”提供通用上手与设备语音说明；本页进一步补充最佳设备搭配、当前 V2 / P2 Pilot 的图字学习、打印和能力边界。

## 最佳体验与设备推荐

为了获得最流畅的语音发音、舒适护眼的交互和无忧的数据保障，强烈建议按以下组合使用影伴：

1. **首选平板电脑（iPad / 安卓平板）**
   - **大屏护眼防疲劳**：生字笔顺临摹、生字图卡与大字点读更加舒适，减少孩子低头眯眼的视觉疲劳。
   - **儿童自主触控探索**：平板可立于桌面支架上，孩子伸手指即可自主点字、读题、听古诗，无需家长全程举着手机陪读。
2. **推荐 Google Chrome 浏览器**
   - **完整硬件音频加速**：Chrome 原生支持标准 Web Audio 引擎与 PWA 离线技术，发音响应极速且音质清晰。
   - **避免应用内浏览器限制**：微信等应用内浏览器对音频自动播放和后台离线缓存存在策略限制，可能导致发音静音或需频繁点击；使用系统的 Chrome 浏览器体验最佳。
3. **免费登录开启云端数据同步**
   - **数据永不丢失**：未登录时打卡和积分仅保存在当前浏览器本地，一旦清理浏览器缓存、误开无痕模式或更换设备，数据便会丢失；家长只需免费登录，系统即可自动多副本安全备份。
   - **多端无缝协同**：孩子在平板上自主打卡学习，家长在手机随时查看进度，积分心愿兑现与家庭成长日历多端实时拉齐。

## 三步极速上手

1. **家长登录**：点击右上角“登录”，选择邮箱验证码或邮箱密码。验证码可完成首次注册或登录；尚未设置密码时，登录后会提示设置，也可以稍后处理。孩子不需要单独注册账号。
2. **建立家庭空间**：填写家庭名称和第一个学习者。进入家庭空间后，可以添加孩子、修改姓名和年级，并切换当前孩子。
3. **开始学习**：从左侧进入“学习”，再选择语文、数学、英语或绘本。每个任务单独打卡，再次点击同一按钮即可取消该任务。

## 学习模块与日历

影伴有四个学习打卡模块：语文、数学、英语和绘本。它们统一收纳在左侧一级入口“学习”下；“积分”“成长”“指南”和“设置”是独立的一级页面。首页“今日打卡”显示当天已完成的模块数，例如 `2/4` 表示完成了其中两个模块。语文里的识字、古诗和写字虽然是三个独立任务，但同一天只计作 1 个语文模块。

“成长”页面的近 30 天打卡日历按模块统计。每个日期格会显示 `已完成/4`，颜色和图例对应当天完成的模块数，黄色边框表示今天；因此格内的 `4/4` 表示四个学习模块全部完成，不是四条任务记录。

“积分”页面的日历独立记录行为积分，不计入成长模块数量。日期颜色分别表示无积分、有加分、有扣分，或同一天同时有加分和扣分；黄色边框表示当前选中的日期，可用于查看或补记该日积分。

### 奖励约定与兑现

“成长”页面支持家长与孩子设定积分奖励约定（例如“周末去公园”、“挑选一本新绘本”）：
- **心愿货架与重复兑换**：心愿约定作为可复用的家庭契约模板，在兑现后自动解耦。只要孩子可用积分充足，卡片随时支持「再次兑换」（积分不足则正常置灰），绝不会因历史兑现而被永久锁死。
- **履约与防误触安全窗**：孩子发起兑换后卡片进入“待兑现”状态；家长在现实生活中完成约定后点击「确认兑现」完成激励闭环。若计划有变可在待兑现时直接点击「取消兑换」退还积分；若家长误触点击了兑现，在**兑现后 24 小时内**卡片会保留「撤回兑现」入口及「已兑现 · 24小时内可撤回」提示，点击可撤回履约并退回积分；超过 24 小时后履约自动归档，撤销入口安全关闭。
- **家庭同步（已登录）**：兑换记录会自动通过云端原子校验，多设备之间积分状态保持一致；断网离线时的兑换会先记为“待联网确认”，连网完成云端确认后即可正常兑现。

### 今日图字学习、轻量临摹和 A4 打印

当前语文模块使用启蒙学习包 V2 / P2 Pilot 的 `hanzi-v2-pilot-1` 内容版本。这是当前的试运行图字学习切片，不是完整课程：本指南不承诺完整 200/400 字，也不提供 SM-2 复习评分或 mastery 文案。

实际路线是：**学习 → 语文 → 今日图字学习 → 中文发音 / 英文发音 / 朗读字意 → 笔顺与书写提示 → 打印 A4 字帖**。

“今日图字学习”会先显示 4 张学习卡。每张卡都有视觉提示、词语、目标字、拼音、单字字意、笔顺符号、例句和书写提示；屏幕学习卡不展示字帖或田字格，书写练习在打印稿中完成。中文发音和英文发音按钮分别朗读当前单字（例如 `火` / `fire`）；顶部视觉卡片的 `火山` / `volcano` 只是实例词组。字意朗读只朗读单字字意，图片描述不重复放入字意区域。按钮只作用于当前卡；播放失败可以重试，不会改变学习状态，连续点击同一按钮不会重复启动语音。固定课程发音优先播放共享 CDN 上的 AI 合成音频；只有该音频不可用时才尝试同语言的系统语音。

同一天刷新页面、切换到其他模块再回来，4 张卡的 assignment、日期、内容版本、汉字顺序和练写行保持同一份 snapshot；进入新的一天后才会生成新的 assignment。点击“打印 A4 字帖”会先准备打印样式和字体，准备完成后再打开浏览器打印流程，避免先闪现未排版的页面；样式加载失败会提示重试，字体加载超时则回退系统字体。打印只包含当前这份丰富图字学习 snapshot，不会把导航、按钮、古诗或其他模块一起打印，Shadow Mate 标识内置在打印快照中，不依赖外部图片加载。A4 字帖按确认版式一页 4 字，每字使用 1 个楷书示范格、4 个描红格和 4 个临写格，并包含组词、造句和自评区。点击“完成今日打卡 · 写字”会记录当天的写字任务；再次点击可以取消当天的打卡标记，但不会删除已经留下的字帖完成记录。

## 听发音与系统语音兜底

当前工作区已补齐识字卡、写字卡图片、两个词语、例句与书写说明的点读，以及古诗、口算、数感/数独提示和英语单词的 CDN 音频。点击图片朗读概念名称与图片说明；点击词语读对应词语；点击例句读例句；点击书写提示读提示文字。字意区域仍使用“朗读字意”按钮的音频。

每日轮换的内容来自固定库，音频覆盖整个当前库。口算题随机生成，朗读时组合数字、加/减和“等于几”片段；切换日期或口算范围无需现场合成。2026-09-09 用户已确认小米夸克通过局域网开发页面试听通过；正式网站需部署后另行验收。

影伴在发布前用腾讯云语音合成生成固定课程音频：中文使用智柯，英文使用 WeJack。生成后的 MP3 由 `voice.shadow.wang` 统一提供，所有浏览器共享同一份源文件，并由浏览器按标准 HTTP 规则缓存；不需要下载本地模型，也不会在点击时产生云端合成费用。若共享音频加载、校验或播放失败，页面只尝试对应语言的系统语音。影伴不采集麦克风录音。

### Windows

打开“设置 → 时间和语言 → 语言和区域”，在 English 的“语言选项”中下载“语音 / Text-to-speech”。

[微软：管理语言和键盘设置](https://support.microsoft.com/windows/change-your-keyboard-layout-245c49b8-f856-7fd7-2cf5-41e54c66f5b3)

### macOS

打开“系统设置 → 辅助功能 → 朗读内容”，在“系统声音 → 管理声音”中下载 English 语音。

[Apple：更改 Mac 用于朗读文本的声音](https://support.apple.com/guide/mac-help/change-the-voice-your-mac-uses-to-speak-text-mchlp2290/mac)

### iPhone / iPad

打开“设置 → 辅助功能 → 朗读内容 → 声音”，选择 English 并下载需要的声音。Safari 需要在用户点击“听发音”时播放，因此不要使用系统静音模式。

[Apple：在 iPhone、iPad 或 Mac 上使用 Live Speech](https://support.apple.com/en-us/105018)

### Android

打开“设置 → 无障碍 → 文字转语音输出”，选择可用引擎和 English，然后进入“安装语音数据”下载英语语音。不同品牌的菜单名称可能略有不同。

> 国产 Android（无 Google 服务）可能没有可用系统语音，但正常情况下仍直接播放共享 CDN 音频。只有 CDN 音频也失败时，才会看到系统语音不可用提示。旧 Matcha 语音包已停用；曾下载过的浏览器可在应用指南的资源管理区手动删除它以释放空间，页面不会自动删除可能仍被其他标签页使用的缓存。

新增或修改课程文案时需更新语音目录，预热缺失音频并通过 CDN 回读校验，再进行代表性试听。当前清单为 634 条；维护命令见[架构文档](architecture.md#speech-catalog-maintenance)。页面不会在用户点击时生成或上传语音。系统语音列表为空时会尝试按请求语言调用浏览器默认语音；若浏览器没有对应能力，仍可能失败。离线播放取决于浏览器是否保留了相关音频缓存。

[Google：Android 文字转语音输出](https://support.google.com/accessibility/android/answer/6006983?hl=en)

如果仍然没有声音，请检查网络、设备音量、静音开关、蓝牙输出设备和浏览器的声音权限。页面会区分共享 AI 音频加载失败、超时以及系统语音未能启动，便于判断应重试网络还是调整系统语音。

### 声音与语音音量设置

影伴提供独立的“声音设置”（左侧导航“设置”）：
- **界面音效**：提供音效总开关、总音量滑块与 5 类学习事件的音效变体选择。总音量默认 60%（采用 1.5 倍基准增益 + 2.8kHz 清晰度增强 + 动态限幅防爆音），支持最高 200% 的超额放大滑块（滑过 100% 显示超额增强，最高达 5.0 倍增益）。
- **课程语音朗读音量**：独立调节汉字单字发音、英文读音与字意朗读的音量。默认音量为 60%（采用 3.0 倍基准增益 + 人声 3kHz 穿透力增强 + 广播级动态压缩），既保证在手机与平板扬声器上清晰洪亮且不爆音，又提供最高 200% 的超额放大滑块（滑过 100% 显示超额增强，最高达 10 倍增益）。语音朗读与界面音效相互独立，即使关闭了界面音效，孩子依然能正常收听课程发音。
- 所有声音设置仅保存在当前设备本地（localStorage），不会同步到云端。

## 家庭空间与同步

- 家庭空间是家庭成员、孩子档案和同步操作的统一入口。
- 学习记录按孩子分别同步，避免多个孩子的打卡、积分和绘本记录混在一起。
- 家庭空间显示所有孩子记录中的最近同步时间。
- 切换孩子后，页面会加载该孩子对应的学习记录。
- 切换孩子时，应用会先确认本机和云端都已进入新孩子的作用域；如果短暂读到了旧的 Growth Loop 作用域，会在当前切换仍有效时自动重试一次。仍无法确认时会保持安全保护并提示重试，不会把学习记录写入错误的孩子。
- 家庭所有者可以在账号面板导出完整家庭 JSON 数据。
- “删除全部家庭数据”会删除当前家庭的云端学习数据、清理本机数据并退出登录；共享 Supabase 项目中的 Auth 身份不会被删除，之后仍可用同一邮箱登录。
- 如果孩子切换时本机作用域或事务无法安全确认，页面会暂停本机和云端写入并保持 fail-closed 状态；关闭标签页、刷新页面或普通退出登录不会自动解除保护。确认不需要保留本机记录后，在账号面板明确点击“清除本机数据”（或完成删除家庭/账号的本机清理流程）才会清除该保护。
- 清除本机数据是可重试操作：本机 localStorage 或 Growth Loop IndexedDB 任一清理失败时，保护标记会继续保留，不会恢复写入；修复本机环境后再次点击“清除本机数据”即可重试。

## 共享密码

- 密码至少 6 位，强度提示会根据长度以及字母、数字、符号组合显示弱、中、强。
- 密码属于同一个 Supabase Auth 账号。在影伴设置或修改后，共用该账号系统的其他 Shadow 产品也使用同一密码。
- 忘记密码时，在“邮箱密码”登录页点击“忘记密码”。如果邮箱已注册，会收到按发起产品显示品牌的重设邮件；页面不会暴露邮箱是否存在。
- 所有提交按钮在处理期间会暂时禁用；快速重复点击不会重复创建孩子或重复执行云端操作。

## 安装到主屏幕（PWA 独立安装）

影伴基于现代渐进式 Web 应用（PWA）技术构建，不需要在应用商店搜索或下载第三方 APK，通过浏览器即可将影伴“添加到主屏幕”，享受媲美原生 App 的独立使用体验：

### 为什么推荐安装到主屏幕？
- **全屏沉浸无干扰**：隐藏浏览器的网址栏与导航按键，全屏纯净展示，孩子点读学习更专注，避免误触跳转其他网页。
- **系统独立进程长久保活**：操作系统为桌面图标分配专属独立沙盒，登录状态长效保持（配合 localStorage 持久化），彻底告别频繁掉登录。
- **秒开与离线能力**：课程资源由本地 Service Worker 与浏览器缓存智能管理，网络不稳定时也能快速启动并打卡。

### 详细安装步骤

1. **iPad / iPhone (iOS Safari 浏览器)**
   - 在系统自带的 **Safari 浏览器** 中打开影伴（若在微信中打开，先点击右上角「···」选择“在 Safari 中打开”）。
   - 点击屏幕底栏（iPhone）或顶栏（iPad）的 **「分享」图标**（带有向上箭头的方框）。
   - 在弹出的分享菜单中向下滑动，找到并点击 **「添加到主屏幕」**（Add to Home Screen）。
   - 在右上角确认点击 **「添加」**，主屏幕就会生成绿色的“影伴”独立应用图标。

2. **Android 平板 / 手机 (Google Chrome 浏览器)**
   - 使用系统自带或安装的 **Google Chrome 浏览器** 打开影伴。
   - 点击浏览器右上角的 **三个点「⋮」** 菜单。
   - 选择 **「添加到主屏幕」** 或 **「安装应用」**（部分系统在底部会直接弹出“安装影伴”快捷横幅）。
   - 点击确认，系统即可在桌面自动生成独立的影伴应用图标。

3. **电脑端 (Windows PC / Mac)**
   - 使用 Chrome 或 Edge 浏览器打开影伴网页。
   - 观察浏览器地址栏最右侧，会看到一个 **显示屏带箭头的「安装应用」小图标**。
   - 点击该图标并选择 **「安装」**（或通过浏览器右上角菜单选择“安装影伴”）。
   - 安装后自动生成桌面快捷方式，支持固定到任务栏或 Dock 栏独立窗口运行。

不需要从陌生来源下载任何 APK 或可执行文件，影伴由浏览器沙盒提供原生级安全隔离。

## 本机数据与云端数据

未登录时也可以使用，学习记录保存在当前浏览器。本机数据不会因为普通刷新消失，但清除网站数据、无痕模式、浏览器自动清理或更换域名可能会清除本机记录。登录并同步后，云端记录可用于跨设备恢复。
