# Shadow Mate Roadmap

> 本文只记录主产品 Web/PWA 的后续方向，不代表已实现、已发布或已通过生产验收。小红书小工具是独立适配目标，不在本文中混入实现。

## 下一阶段：移动端学习体验

目标是让手机和平板上的学习、点读和打卡流程稳定可用，并用真实设备验收，而不是只依赖桌面浏览器或单台手机观察。

实施顺序：

1. 用 Playwright 固化 360px、390px、平板横竖屏和桌面断点，检查横向溢出、底部导航、弹层、触控热区、软键盘和安全区。
2. 在 iPhone/iPad、国内安卓手机/平板和常见 WebView 上验证首页、学习模块、打卡、积分、成长和语音失败/恢复路径。
3. 按真实问题做最小 CSS/交互修复，确保关键操作不依赖 hover，保留 local-first 和现有数据模型。
4. 发布候选前形成设备矩阵和逐项验收记录；单台设备通过不代表全平台通过。

## 下一阶段：移动设备字帖输出

目标是解决手机上浏览器打印入口不稳定的问题，同时保持桌面端 A4 打印能力。

### 推荐路径

- 从现有 worksheet snapshot 抽出确定性渲染数据和版式参数。
- 用 Canvas 2D 生成本地 PNG/JPEG，保持 Logo、字形、田字格、组词、例句和自评区一致。
- 手机端优先使用系统分享/保存能力；能力不可用时提供图片预览并提示用户长按保存。
- 输出必须由用户主动点击触发，失败时不改变写字打卡状态。

### PDF 边界

- 桌面端继续使用浏览器打印并由系统导出 PDF。
- 移动端只在实际设备支持时提供系统打印/分享入口，不承诺所有手机都能直接生成或保存 PDF。
- 不引入服务端 PDF 生成，主产品仍保持 local-first。

### 验收要求

- 同一份 snapshot 在屏幕、桌面打印和图片输出中的内容一致。
- 图片输出不依赖外链字体或图片。
- 覆盖 iOS Safari、Android Chrome 和常见 WebView 的保存/分享失败路径。
- 小红书版本若未来保存图片，单独使用其 `window.xhs.miniTool.writeTempFile` / `saveImageToPhotosAlbum`，并单独申请相册权限；不与主产品 Web 版实现混合。
