# Dogfooding 与小规模内测清单

更新时间：2026-08-12

## 当前放行结论

当前允许由独立开发者 Ward Lu 以个人名义进行非商业 Dogfooding 和小规模邀请制内测。该放行不等于正式商业化，也不等于商标、IP、第三方许可证或儿童隐私法律清权。

## 内测边界

- 仅邀请已知测试者，不公开招募，不收费，不接入 Pro、订阅或支付。
- 内测说明应写明：独立开发者 Ward Lu、非商业内测、商标尚未注册、功能可能变化。
- 不使用“官方版”“官方 Cloud”“Shadow Mate Pro”或 `®` 等表述。
- 当前只验证基础朗读，不采集麦克风录音，不做家长或儿童声音克隆。
- 优先使用昵称、模拟学习数据和成人测试账号；确需使用真实儿童数据时，由家长/监护人直接操作并先阅读当前隐私说明。
- 当前 Piper 仅作为现有版本的过渡实现使用；不得把当前 Piper 路线描述为商业许可已清零，也不得据此承诺商业再分发。

## 首轮测试矩阵

- [ ] 国产 Android、无 GMS：系统无英语语音时完成 Piper 下载、合成、离线再次播放。
- [ ] 系统存在英语语音：确认优先使用系统 TTS。
- [ ] 系统语音列表可用但无响应：确认能超时并回退到 Piper。
- [ ] 下载取消、下载失败、离线、存储空间不足：确认有明确提示和可重试路径。
- [ ] 数据生命周期：创建学习者、导出家庭数据、删除学习者/家庭，并核对结果。
- [ ] 隐私观察：确认朗读文本没有被发送到当前影伴服务器；不上传录音。
- [ ] 反馈记录：记录设备型号、系统版本、浏览器、网络、语音路径和错误信息，不记录不必要的儿童个人信息。

## 内测结束条件

扩大用户范围前，应完成首轮矩阵、至少一次数据删除验证、关键错误归档，并确认所有对外说明仍与当前 TTS、隐私和商标文档一致。

## 尚未放行的事项

- 自托管 MeloTTS API 及国产 Android 生产替换；
- 商业构建移除 Piper WASM、phonemizer 和模型；
- 目标市场商标检索、正式 IP 权属链和未来主体承接；
- 可验证家长同意、数据保留/删除 SLA、子处理者和跨境处理法律审核；
- 支付、Entitlement、备份、告警和事故响应。
