# Shadow Mate 产品路线

本路线记录产品方向，不代表功能已经实现、发布或上线。具体交付仍需独立规格、内容审核、工程验证和发布授权。

## 当前优先级

### 学前学习包基础体系

- 统一为一套学前学习系统和一套学习引擎。
- 启蒙学习包 V1、V2、V3 分别对应 P1、P2、P3。
- 较高阶段采用累计内容池；直接进入 V2 的学习者仍需按基础内容补充尚未接触的 P1 字。
- 当前 MVP 优先推进启蒙学习包 V2 Pilot + SHA-16 字帖轮动和打印闭环：验证同日稳定、次日轮换、离线可用、屏幕/打印一致和 learner 隔离。
- MVP 默认沿用现有打卡和 local-first 能力，不增加阶段选择，不以完整 200 字或 SM-2 复习交互作为上线门槛。

当前代码注册表对应的是 4–5 岁的启蒙学习包 V2 / P2，内部标识为 `foundation-v2`；读取旧的 `foundation-v1` 配置时只更新包元数据，保留各模块启停状态，不需要数据库迁移。这不表示启蒙学习包 V1 / P1 已经实现，V1 仍按下方 roadmap 重新设计。

### MVP 后第一阶段

- 接入独立的 `sm2-compat-v1` 纯函数、共享测试向量、家长确认评分和复习队列。
- 将 V2 Pilot 扩展为累计 200 字内容集，并接入每日新字预算、复习压力控制和 P1 基础内容混排。
- 再评估阶段选择、阶段切换和普通话系统语音。

## 下一阶段

### 各模块内容深度审计与丰满化

当前语文、数学、英语和绘本内容均以较薄的静态集合为主。后续按模块建立内容盘点、阶段目标、主题、难度、来源和质量门禁：

- 语文：汉字之外的词语、短句、古诗、阅读和写字准备。
- 数学：数量感、空间、分类、运算、规律和适龄互动。
- 英语：听辨、主题词汇、词组、短句和分级阅读准备。
- 绘本：年龄标签、阅读目标、互动问题、复述和阅读记录。
- 跨模块：每日负荷、提示强度、复习策略和家长反馈口径。

这项工作独立于当前汉字轮动任务，不在本次实现中顺带扩张。

### 启蒙学习包 V1 / P1 重设计

- 面向 3–4 岁重新设计整体体验和跨模块内容。
- 重点是看图、听音、数量感、动作、控笔和低负担互动。
- 当前 V2 可以把既有 P1 80 字作为累计基础内容，但 V1 自身的汉字教学方式仍需单独完成教育内容评审后再实现。

### 启蒙学习包 V3 / P3 接入

- 接入已设计的 P3 汉字内容集。
- 增加短句、阅读准备、学校生活、时间、安全和科学启蒙内容。
- 在同一学习引擎上提高独立识别、书写准备和任务复杂度。

## 后续能力

- 为 V1 / P1 和 V3 / P3 分别冻结每日新内容范围和复习容量，并根据真实家庭使用反馈调优三阶段策略。
- 评估 `sm2-compat-v1` 是否适用于英语词汇和原子数学事实；绘本和完整学习活动不默认接入。
- 建立跨模块内容版本、来源、版权和审核流程。
- 当非开发人员确实需要编辑、审核和撤回内容时，再评估内容管理服务。
- 当 JSONB 状态、跨用户统计或推荐需求成为实际瓶颈时，再评估事件表和规范化数据模型。
