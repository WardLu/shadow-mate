# 学前学习采用一个系统与三个阶段学习包

Shadow Mate 采用一套学前学习系统和一套学习引擎，内部保留 P1、P2、P3 三个阶段内容目录；产品名称统一为启蒙学习包 V1、V2、V3。选择这一结构，是为了保留各年龄阶段经过审核的内容边界，同时避免为英语、数学、语文和绘本复制三套页面、状态、同步和复习逻辑。

## Considered Options

- 三套独立学习系统：阶段边界清晰，但重复内容、状态和迁移成本过高。
- 单一内容池只按年龄动态抽取：实现集中，但难以保证课程首次引入顺序和内容审核边界。
- 一个系统、三个阶段学习包、阶段内自适应：保留课程边界，并允许每日数量、提示和复习计划按学习者表现调整；采用此方案。

## Consequences

- 启蒙学习包 V1、V2、V3 分别对应 P1、P2、P3；内容发布修订使用独立的内容版本。
- 较高阶段使用累计内容池；`firstExposureStage` 只表示课程归属，不能用来推断儿童已经学习或掌握较低阶段内容。
- 家长切换阶段只改变新内容准入，既有接触和复习历史继续保留；系统不会按年龄或一次表现自动跨阶段。
- 当前交付先处理启蒙学习包 V2 / P2，并把既有 P1 80 字作为其累计基础内容；这不等于交付 V1 产品体验。V1 整体内容仍需重新设计，V3 / P3 后续接入同一引擎。
- MVP 先交付 V2 Pilot + SHA-16 字帖轮动；完整 200 字、SM-2 复习交互和阶段选择属于后续增量，不作为 MVP 门槛。
- V2 Pilot 是完整 V2 累计课程目标池的可验证子集，使用独立内容版本标识，不把未纳入 Pilot 的课程目标字视为已掌握。
- 当前汉字排程冻结独立的 `sm2-compat-v1` 契约，不直接依赖 Quick-flomo 服务或数据表，也不把该调度模型强制套用于绘本和完整学习活动。
- 各模块当前内容深度不足的问题进入产品 roadmap，不扩大本次汉字与轮动范围。
