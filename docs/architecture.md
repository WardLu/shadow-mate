# Shadow Mate architecture

Shadow Mate is a Vite and vanilla-JavaScript local-first PWA. `src/app.js` owns the UI and local learning state, `src/cloud.js` owns authenticated household synchronization, and Supabase changes in this repository are proposals for the shared Shadow Portal control plane.

## Fixed curriculum speech

`src/tencent-tts-catalog.js` derives stable speech IDs and content-addressed object keys from the tracked writing curriculum. The release-only `scripts/tencent-tts-prewarm.mjs` calls Tencent Cloud TTS with Zhike (`101030`) for `zh-CN` and WeJack (`101050`) for `en-US`, uploads only missing immutable MP3 objects to COS, verifies every object through `voice.shadow.wang`, and atomically writes the public manifest only after all readbacks pass.

At runtime `src/tencent-tts-player.js` reads that manifest and plays CDN audio. Standard HTTP caching provides repeat reuse; there is no public synthesis endpoint and no Tencent credential in the browser or Vercel. Playback routes through the Web Audio API with a scalable gain multiplier (`5.0x` / `+14 dB` at 100%, defaulting to `60%` volume delivering `3.0x` / `+9.5 dB` baseline gain, and supporting up to `200%` excess boost delivering `10.0x` / `+20 dB`), a vocal presence peaking filter (+3.5 dB @ 3000 Hz) for piercing voice clarity on mobile speakers, and a broadcast-grade dynamic range compressor (`DynamicsCompressorNode` at -12 dBFS threshold, 4:1 ratio, 3ms attack) to maximize perceived loudness without digital distortion or clipping, falling back to standard `Audio` elements if Web Audio is unavailable. Decoded `AudioBuffer` objects are cached in memory for zero-latency repeated taps, and active speech is interrupted cleanly via `player.stop()`. Device-local speech volume (`speechVolume`, default `60%`, range 0%~200%) is configured independently from UI sound effects under Settings (`声音与音效设置`) and stored in `localStorage`. A failed CDN clip may fall back only to a verified system voice for the requested locale. The retired Matcha/Piper assets remain in the app shell solely for rollback history and explicit deletion of old browser caches.
